# 累積 DAILY REP

繁體中文、手機優先的個人健身紀錄網站，使用 HTML、CSS 與 JavaScript，無須安裝套件。

## 功能

- 自動帶入裝置當天日期，可切換日期補記。
- 依照指定的一週課表顯示當日訓練。
- 自訂動作，新增或移除組數，記錄每組重量與次數。
- 顯示前一次相同動作紀錄；進步紀錄比較歷次組數、最高重量與總訓練量。
- 自動儲存至 localStorage，支援 JSON 備份匯出與匯入。

## GitHub Pages 部署

1. 在 GitHub 建立儲存庫，將此資料夾內的檔案推送至儲存庫的 `main` 分支。
2. 進入儲存庫 **Settings → Pages**，Source 選擇 **Deploy from a branch**。
3. Branch 選擇 **main**，資料夾選擇 **/ (root)**，按下 Save。
4. 等待 Pages 部署完成後，開啟 GitHub 顯示的網站網址，手機亦可使用。

也可直接開啟 `index.html` 試用；正式使用建議使用固定網站網址，以確保瀏覽器儲存來源一致。

## 資料與比較規則

資料僅保存在目前裝置與瀏覽器中，不會同步至 GitHub 或其他裝置。網站網址、瀏覽器或裝置改變時，請使用 JSON 匯出／匯入搬移資料。清除網站資料會刪除紀錄，請定期備份。匯入會取代所有目前資料，需確認後才執行。

相同動作名稱視為同一動作；重量與次數均填寫後才計入統計。徒手訓練重量可填 0。總訓練量為每組「重量 × 次數」的加總，最高重量變化與前一個有完整紀錄的日期比較。花式跳繩亦可自行新增動作、以 0 kg 記錄次數。

## 本機預覽

安裝 Node.js 後執行 `node server.cjs`，開啟 http://localhost:4173 。
