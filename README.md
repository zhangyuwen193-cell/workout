# 健身APP

繁體中文、手機優先的個人健身紀錄網站，使用 HTML、CSS 與 JavaScript，無須安裝套件。

## 功能

- 自動帶入裝置當天日期，可切換日期補記。
- 依照指定的一週課表顯示當日訓練。
- 自訂動作，新增或移除組數，記錄每組重量與次數。
- 顯示前一次相同動作紀錄；進步紀錄比較歷次組數、最高重量與總訓練量。
- 自動儲存至 localStorage，支援 JSON 備份匯出與匯入。
- 固定兩位使用者，以姓名卡片切換，各自保留訓練紀錄、統計與動作歷史。
- 預備 Email／密碼登入與 Firebase 雲端同步，含待上傳佇列、即時更新與版本衝突保護。**尚需設定 Firebase 專案才會啟用**，詳見 [CLOUD_SETUP.md](CLOUD_SETUP.md)。

## 跨裝置同步設定

**可改用 Google 試算表＋Apps Script，無須 Firebase。** 詳見 [試算表同步設定](APPS_SCRIPT_SETUP.md)：將 `apps-script/Code.gs` 貼入專用試算表的 Apps Script，執行 setup 並部署，再把 `/exec` 網址填進 `apps-script-config.js`。已填入 Apps Script 部署網址，並驗證服務健康回應、錯誤同步碼拒絕與跨來源回應標頭。兩人需以各自同步碼連接，資料分開儲存，開啟頁面時每 30 秒檢查更新。尚未以有效同步碼驗證真實紀錄讀寫與雙裝置同步。

無需安裝 Codex 插件。請依 [設定說明](CLOUD_SETUP.md) 建立 Firebase Authentication、Cloud Firestore 與兩人身分對應，再填入 `firebase-config.js` 的公開網頁設定。不要提交密碼、服務帳號私鑰或管理員憑證。設定完成前仍為本機模式；目前未執行真實雲端、雙裝置與安全規則驗收。

設定後，各自使用同一 Email／密碼在不同裝置登入，紀錄與課表會依登入身分同步。第一次登入先保留本機備份；另一裝置已有不同修改時會顯示衝突，由使用者選擇版本。離線修改暫存本機，恢復連線後重試。

本機驗證：`node check.cjs`、`node sync-check.cjs`、`node apps-script-check.cjs`。

## 固定兩位使用者

使用者固定為「張語宸」與「張祐綸」，在畫面上方點選姓名卡片即可切換。選取者會以深綠底、「目前使用中」與下方完整姓名標示。沒有新增、刪除或改名功能，兩人的訓練紀錄、比較與課表各自獨立。

舊版資料升級時優先依相同姓名對應，其餘依原本建立順序對應給兩人。舊版 localStorage 保留不覆寫；超過兩位的額外資料保存在新版資料的 archivedUsers 中。新版使用 daily-rep-v3 儲存，重新載入不會重複移轉。

未設定雲端時，使用者為此瀏覽器內的個人檔案，無登入驗證，不同手機不會自動同步。同一瀏覽器可切換查看兩人的本機資料。匯出與匯入僅針對目前選取的人，換手機後先選正確姓名再匯入備份。

## 編輯每週課表

切換到「每週課表」，按「編輯每週課表」，即可設定星期一至日的訓練內容，休息日填「休息」。課表依使用者獨立儲存，預設沿用最初指定的安排；修改後立即更新當日訓練提示，不會改動已記錄的動作。每位使用者的 JSON 備份包含自訂課表。匯入沒有課表的舊版備份時，保留目前課表。

匯出只包含目前使用者的紀錄，檔名包含姓名；請為每位使用者分別備份。匯入（包含舊版備份）只取代目前使用者的紀錄，不影響其他人。換裝置時先選正確姓名再匯入其備份。舊版儲存資料會保留，以利復原。

## GitHub Pages 部署

1. 在 GitHub 建立儲存庫，將此資料夾內的檔案推送至儲存庫的 `main` 分支。
2. 進入儲存庫 **Settings → Pages**，Source 選擇 **Deploy from a branch**。
3. Branch 選擇 **main**，資料夾選擇 **/ (root)**，按下 Save。
4. 等待 Pages 部署完成後，開啟 GitHub 顯示的網站網址，手機亦可使用。

也可直接開啟 `index.html` 試用；正式使用建議使用固定網站網址，以確保瀏覽器儲存來源一致。

## 資料與比較規則

未設定雲端時，資料僅保存在目前裝置與瀏覽器中，不會同步至 GitHub 或其他裝置。可使用 JSON 匯出／匯入搬移資料。清除網站資料會刪除未同步的紀錄，請定期備份。匯入會取代目前選取使用者的資料；啟用雲端時亦會排入雲端上傳，需確認後才執行。

相同動作名稱視為同一動作；重量與次數均填寫後才計入統計。徒手訓練重量可填 0。總訓練量為每組「重量 × 次數」的加總，最高重量變化與前一個有完整紀錄的日期比較。花式跳繩亦可自行新增動作、以 0 kg 記錄次數。

## 本機預覽

安裝 Node.js 後執行 `node server.cjs`，開啟 http://localhost:4173 。
